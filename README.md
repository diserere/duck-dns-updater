# duck-dns-updater

Небольшой Bash-скрипт для обновления динамических DNS-записей на [DuckDNS](https://www.duckdns.org/).

## Настройка

Нужны Bash, `curl` и `column` (последняя команда используется для отображения журнала). Скопируйте пример конфигурации и укажите свои домены и токен DuckDNS:

```bash
cp .env.example .env
```

Отредактируйте `.env`. Переменная `DOMAINS` содержит имена доменов через запятую, `TOKEN` — токен DuckDNS, `TZ` — часовой пояс для отметок времени (по умолчанию `UTC`), `IP` — необязательный IP-адрес. Пустой `IP` позволяет DuckDNS определить адрес запроса.

Не добавляйте `.env` в Git: в нём находятся персональные настройки и токен.

## Запуск

```bash
./duck-dns-updater
```

Для периодического обновления, например через cron каждые пять минут, можно добавить такую строку, подставив абсолютный путь к скрипту:

```cron
*/5 * * * * /путь/к/duck-dns-updater/duck-dns-updater -v -d >/dev/null 2>&1
```

## Аргументы

Скрипт обрабатывает аргументы в фиксированном порядке; используйте их в таком порядке:

| Аргумент | Действие |
| --- | --- |
| `-tz ЧАСОВОЙ_ПОЯС` | Задать часовой пояс для отметки времени; должен идти первым. |
| `-v` | Запросить подробный ответ DuckDNS. |
| `-d` | Добавлять результаты в `duck-dns-updater.log`. |
| `-u` | Вместе с `-d` не записывать ответы `NOCHANGE`. |
| `-l` | Показать журнал. |
| `-R` | Очистить журнал. |

Примеры:

```bash
./duck-dns-updater -v
./duck-dns-updater -v -d
./duck-dns-updater -v -d -u
./duck-dns-updater -l
./duck-dns-updater -R
```
