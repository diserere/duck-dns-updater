# duck-dns-updater

Небольшой Bash-скрипт для обновления динамических DNS-записей на [DuckDNS](https://www.duckdns.org/).

## Настройка

Нужны Bash, `curl` и `column` (последняя команда используется для отображения журнала). Скопируйте пример конфигурации и укажите свои домены и токен DuckDNS:

```bash
cp .env.example .env
```

Отредактируйте `.env`. Переменная `DOMAINS` содержит имена доменов через запятую, `TOKEN` — токен DuckDNS, `TZ` — часовой пояс для отметок времени (по умолчанию `UTC`), `IP` — необязательный IP-адрес. Пустой `IP` позволяет DuckDNS определить адрес запроса. Файл `.env` загружается Bash-командой `source`, поэтому используйте только созданный и проверенный вами файл.

Не добавляйте `.env` в Git: в нём находятся персональные настройки и токен.

## Запуск

```bash
./duck-dns-updater
```

Чтобы получить строку для cron с абсолютным путём к скрипту, выполните:

```bash
./duck-dns-updater --print-cron
```

Команда выведет расписание каждые пять минут. Скопируйте строку в crontab командой `crontab -e`; скрипт сам не меняет crontab.

Журнал при запуске с `-d` сохраняется в `logs/`. Имя файла зависит от имени скрипта, например `logs/duck-dns-updater.log`. Каталог создаётся при первой записи и исключён из Git.

```cron
*/5 * * * * /абсолютный/путь/к/duck-dns-updater -v -d -u >/dev/null 2>&1
```

## Аргументы

Скрипт обрабатывает аргументы в фиксированном порядке; используйте их в таком порядке:

| Аргумент | Действие |
| --- | --- |
| `--print-cron`, `-p` | Вывести готовую строку cron с расписанием раз в пять минут. |
| `-tz ЧАСОВОЙ_ПОЯС` | Задать часовой пояс для отметки времени; должен идти первым. |
| `-v` | Запросить подробный ответ DuckDNS. |
| `-d` | Добавлять результаты в `logs/<имя-скрипта>.log`. |
| `-u` | Вместе с `-d` не записывать ответы `NOCHANGE`. |
| `-l` | Показать журнал. |
| `-R` | Очистить журнал. |

Примеры:

```bash
./duck-dns-updater -v
./duck-dns-updater -v -d
./duck-dns-updater -v -d -u
./duck-dns-updater -l
./duck-dns-updater -R
```
